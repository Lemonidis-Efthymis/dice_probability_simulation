# Dice Probability Simulation

A Python program to **estimate the probability** of rolling a specific sum with **two dice** using Monte Carlo simulation.

The program:
- Rolls two dice `trials` times (default 100,000)
- Counts how often the desired sum appears
- Outputs the probability as a percentage
